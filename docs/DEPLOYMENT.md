# Развёртывание Iskan

Два контура: **сервер** (централизованный, разворачивается через Docker Compose) и **агенты** на рабочих станциях Windows (тихая установка MSI, массовая раскатка).

## 1. Сервер

### Требования

- Linux-хост с Docker и Docker Compose.
- Ориентир для ~100–200 агентов: 4 vCPU / 8–16 ГБ RAM / SSD (объём под скриншоты зависит от интервала и ретеншна).
- Доменное имя и открытые порты: 443 (HTTPS/WSS), 3478 + диапазон UDP для TURN.

### Состав `docker-compose.yml`

- `traefik` — reverse proxy, TLS (Let's Encrypt).
- `api` — API Gateway (.NET).
- `ingestion` — приём телеметрии.
- `signaling` — WebRTC-сигналинг для живого просмотра.
- `ai-worker` — AI-анализ (Python).
- `web` — статика дашборда (React).
- `postgres` — PostgreSQL + TimescaleDB.
- `redis` — кэш/сессии/presence.
- `minio` — объектное хранилище (скриншоты/видео).
- `rabbitmq` — очередь задач.
- `coturn` — TURN/STUN.

### Установка

```bash
git clone https://github.com/mortynemo1-code/iskan
cd iskan/deploy
cp .env.example .env
# отредактировать .env: DOMAIN, пароли БД/MinIO, JWT-секрет, ключи AI, настройки TURN
docker compose up -d
docker compose exec api iskan-cli migrate      # миграции БД
docker compose exec api iskan-cli create-admin # первый администратор
```

После старта — вход в дашборд по `https://<DOMAIN>`, создание организации и генерация **enrollment-токена** для агентов.

### Обслуживание

- **Бэкапы**: дамп PostgreSQL + снапшот бакета MinIO по расписанию.
- **Обновления**: `docker compose pull && docker compose up -d`, миграции через `iskan-cli migrate`.
- **Мониторинг**: Prometheus + Grafana (экспортёры сервисов), алерты по недоступности и глубине очереди.
- **Масштаб**: вынести Postgres/MinIO на отдельные узлы, поднять несколько реплик `ingestion`/`ai-worker`; для крупных инсталляций — Helm-чарт (K8s).

## 2. Агент (Windows)

### Пакет

- MSI, собранный WiX Toolset; исполняемые файлы подписаны (code signing) во избежание срабатываний антивирусов и SmartScreen.
- Ставит Windows-службу (`LocalSystem`, автозапуск, recovery actions) и session helper.

### Одиночная установка

```powershell
msiexec /i IskanAgent.msi /qn SERVER=https://iskan.company.ru ENROLL_TOKEN=XXXX-XXXX
```

Параметры:

- `SERVER` — адрес сервера.
- `ENROLL_TOKEN` — одноразовый/групповой токен регистрации (получается в дашборде).
- `SCREENSHOTS=1|0`, `INTERVAL=300`, `TRAY=1|0` — опции политики (могут переопределяться сервером).

При первом запуске агент регистрируется, получает клиентский сертификат (mTLS) и `agent_id`, затем начинает сбор согласно политике.

### Массовая раскатка

- **Group Policy (GPO)** — публикация MSI на OU с ПК, параметры через MST-трансформ.
- **Microsoft Intune / SCCM** — развёртывание MSI с командной строкой установки.
- **Скрипт** — PowerShell + `msiexec` через удалённое выполнение.

Политики (интервал скринов, категории, приватность, кейлоггинг вкл/выкл) задаются централизованно на сервере и раздаются агентам — не требуют переустановки.

### Обновление и удаление

- **Авто-обновление**: сервер публикует новую подписанную версию; агент скачивает и обновляется сам.
- **Удаление**: `msiexec /x IskanAgent.msi /qn` или через тот же механизм раскатки; удаление требует прав администратора (tamper-resistance).

## 3. Сеть и порты

| Направление | Порт/протокол | Назначение |
|-------------|---------------|-----------|
| Агент → Сервер | 443 / HTTPS (mTLS) | телеметрия, скриншоты, команды (WSS) |
| Браузер → Сервер | 443 / HTTPS, WSS | дашборд, сигналинг живого просмотра |
| Агент ↔ Админ (медиа) | UDP через coturn (3478 + relay-диапазон) | WebRTC-поток живого просмотра |

## 4. Чек-лист внедрения

1. Развернуть сервер, настроить домен и TLS.
2. Создать организацию, отделы, роли, первого администратора.
3. Оформить правовую часть: уведомить сотрудников, зафиксировать согласие/положение (см. `COMPLIANCE.md`).
4. Настроить политики (интервал скринов, категории, приватность, ретеншн).
5. Сгенерировать enrollment-токен, раскатать агент на пилотную группу.
6. Проверить поступление данных, живой просмотр, отчёты.
7. Массовая раскатка на весь парк ПК.
