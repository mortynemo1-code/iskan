# Памятка сотруднику

Workforce Monitoring — видимая корпоративная система. Иконка в трее показывает статус и не скрывается.

Система может фиксировать приложение, заголовок окна, домен/путь без query, периоды активности, только количество нажатий/кликов и, по политике, снимки/трансляцию экрана. Не записываются введённый текст, коды клавиш, буфер, файлы, переписка, микрофон и веб-камера.

При первом запуске показывается уведомление «Ознакомлен». Окно агента содержит статус, длительность сессии, версию, связь, контакт и сроки хранения.

«Личное время» прекращает снимки и видео; фиксируется только `BREAK`. При live появляется неотключаемое уведомление. Вне графика, при lock и break снимки/видео запрещены.

«Отправить логи» передаёт диагностику без заголовков окон и URL. Свои показатели доступны, если организация включила личный кабинет.
