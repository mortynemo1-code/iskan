# Состав обрабатываемых данных

Хранятся: работник/оргструктура; устройство, Windows SID/username, ОС/версия; UTC-интервалы; процесс/приложение/заголовок; домен и путь без query/userinfo; категория/состояние; количественные keystrokes/clicks/mouse distance; снимки; рабочий стол без звука; кадровые события/вложения; аудит пользователя, IP и user-agent.

Не собираются введённые символы/коды клавиш, содержимое буфера/файлов/сообщений, пароли, query-строки, микрофон и веб-камера.

По умолчанию: события 365 дней, снимки 30, видео 7, аудит 3 года, логи 30 дней. Политики переопределяются. Pin исключает видео из очистки.

Заказчик утверждает приказ, положение, уведомление работников, основание обработки ПДн, ответственного и каналы обращений. Контакт/сроки вводятся в настройках агента.

Для запроса субъекта администратор выгружает ZIP. Удаление требует UUID и фиксируется в append-only аудите.
