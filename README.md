# Iskan — система мониторинга и контроля рабочего времени

**Iskan** — платформа для контроля рабочего времени и продуктивности сотрудников на рабочих станциях Windows. Аналог ManicTime / Kickidler / Hubstaff, ориентированный на простое развёртывание в компании и на сервере, с модулем HR (отпуска/больничные/штрафы) и AI-анализом активности по скриншотам.

## Что умеет

- **Учёт активности** — какие приложения и сайты использует сотрудник, сколько времени, активность/простой.
- **Скриншоты** — периодические снимки экрана с настраиваемым интервалом и приватностью.
- **Категоризация** — автоматическое отнесение времени к «продуктивному / нейтральному / непродуктивному».
- **Живой просмотр экрана** — админ может по запросу подключиться к экрану сотрудника в реальном времени.
- **HR-модуль** — отпуска, больничные, отгулы, график работы, опоздания.
- **Штрафы** — правила и автоматический расчёт нарушений и удержаний с согласованием.
- **AI-контроль** — vision-модель анализирует скриншоты и оценивает, чем реально занят сотрудник, отмечает нарушения политик.
- **Простое развёртывание** — сервер разворачивается одной командой (Docker Compose), агент ставится тихой установкой MSI и массово через GPO/Intune.

## Быстрый старт (после реализации MVP)

```bash
# Сервер
git clone https://github.com/mortynemo1-code/iskan
cd iskan/deploy
cp .env.example .env      # задать домен, пароли, ключи
docker compose up -d

# Агент на ПК (тихая установка)
msiexec /i IskanAgent.msi /qn SERVER=https://iskan.company.ru ENROLL_TOKEN=xxxxx
```
