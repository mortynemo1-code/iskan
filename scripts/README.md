# Эмулятор агентов

После запуска Docker Compose выполните:

```bash
python3 scripts/simulate_agents.py \
  --installation-token 'значение-из-.env' \
  --agents 5
```

Скрипт создаст пять устройств, отправит историю активности за текущий день и
будет посылать heartbeat каждые 30 секунд. Последнее устройство намеренно
перестаёт посылать heartbeat, чтобы через 90 секунд в интерфейсе появился
статус `OFFLINE`. Остановка: `Ctrl+C`.
